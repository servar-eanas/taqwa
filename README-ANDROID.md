# تطبيق تقوى لأندرويد

هذا مجلد تطبيق أندرويد أصلي يحتوي ملفات الموقع ضمن أصول التطبيق، ويضيف جدولة أذان محلية وخدمة تشغيل صوت بالخلفية. لا يتم النشر على Google Play تلقائيًا.

## بناء واختبار APK
افتح GitHub > Actions > Build Taqwa Android app، ثم افتح آخر تشغيل ونزّل artifact باسم taqwa-android-build. ملف app-debug.apk مخصص للتجربة على جهاز أندرويد. يمكن فتح مجلد android-app في Android Studio باستخدام JDK 17 وAndroid SDK 35.

## عمل الأذان بالخلفية
بعد فتح التطبيق وتحميل المواقيت، يرسل الموقع مواقيت اليوم والغد إلى التطبيق الأصلي. التطبيق يضبط منبّهات محلية ويعيد تفعيلها بعد إعادة تشغيل الهاتف، ويحدّث المواقيت يوميًا. يلزم السماح بالإشعارات والمنبّهات الدقيقة وإلغاء تقييد البطارية عند الحاجة. صوت الأذان يُبث من الإنترنت؛ لذلك يحتاج اتصالًا وقت الصلاة. لا يمكن ضمان التنبيه إذا استخدم المستخدم «فرض الإيقاف» من إعدادات النظام أو منع النظام التشغيل بالخلفية.

## النشر الرسمي
1. اختبر APK على هاتف حقيقي: الأذان والشاشة مقفلة وبعد إعادة تشغيل الهاتف.
2. افتح المشروع في Android Studio واختر Build > Generate Signed Bundle / APK لإنشاء Android App Bundle موقّع (.aab).
3. احتفظ بمفتاح التوقيع وكلمة المرور بشكل آمن ولا ترفعها إلى المستودع.
4. أنشئ التطبيق في Google Play Console وجهّز الأيقونة ولقطات الشاشة والوصف وسياسة الخصوصية ومعلومات أمان البيانات.
5. ارفع AAB الموقّع إلى الاختبار الداخلي أولًا ثم اتبع متطلبات Play Console لحسابك قبل الإطلاق العام.

ملف AAB الذي ينتجه سير العمل غير موقّع للنشر، ويجب توقيعه بمفتاحك الخاص.
