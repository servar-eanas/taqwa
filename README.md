# تقوى V21 — مواقيت وموقع وأذكار

## التغييرات
- إصلاح قائمة المحافظة/المنطقة التي كانت معطّلة؛ صارت الدولة ثم المنطقة ثم المدينة قابلة للاختيار.
- زر «استخدام موقعي الحالي» يعمل على HTTPS وعلى الهاتف والكمبيوتر، بشرط موافقة المستخدم على إذن الموقع. الاختيار اليدوي يبقى بديلًا.
- توسيع صفحة الأذكار والأدعية إلى 50 نصًا قرآنيًا ونبويًا تقريبًا، مع البحث والتصنيف ومصدر مختصر لكل نص.
- إضافة مصادر صوت مباشرة وبديلة للأذان ورسائل تشخيص واضحة عند تعذر التشغيل.
- تغيير cache إلى V21 حتى لا تُستخدم موارد التخزين المؤقت من الإصدارات السابقة.

## تفعيل الأذان
افتح صفحة «مواقيت الصلاة»، اختر موقعك، ثم اضغط «تفعيل صوت الأذان» وبعدها «تجربة الأذان». تأكد أن علامة التبويب ليست مكتومة وأن مستوى الصوت مرتفع. عند وقت الصلاة سيحاول الموقع تشغيل الصوت ما دام مفتوحًا ونشطًا. إغلاق المتصفح بالكامل قد يمنع تشغيل الصوت؛ للتشغيل الموثوق بعد الإغلاق الكامل تحتاج تطبيقًا أصليًا بجدولة محلية.

## النشر
فك ضغط ZIP وارفع محتوياته إلى الجذر المنشور على Netlify، ثم انشر جديدًا وافتح الموقع في نافذة خاصة أو نفّذ تحديثًا قويًا.


## V22 — إصلاح التفسير والتثبيت
- صفحة التفسير تستخدم Al Quran Cloud أولًا وQuranEnc كمصدر احتياطي، وتعرض نص الآية مع تفسيرها، وبحثًا وتقسيمًا على صفحات.
- تحفظ آخر تفاسير تم تحميلها محليًا، وتحاول عرض النسخة المحفوظة إذا تعذر الاتصال.
- تحسين manifest وإضافة التقاط مبكر لحدث تثبيت PWA وإرشادات منفصلة لأندرويد وiOS والكمبيوتر.
- يجب رفع محتويات هذا الأرشيف إلى جذر موقع Netlify ثم إعادة النشر. لا يمكن تحويل موقع الويب إلى APK أصلي بمجرد هذه الملفات؛ التثبيت هنا PWA مستقل عند استيفاء شروط المتصفح.
